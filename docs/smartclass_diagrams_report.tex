\begin{abstract}
This document details the software and hardware architecture of the SmartClass mmWave intelligent classroom automation platform. We provide the complete Unified Modeling Language (UML) specifications, including Use Case, Class, Component Architecture, and Sequence diagrams representing both the React/Firebase edge application and the ESP32 LD2410 24\,GHz radar firmware.
\end{abstract}

\section{System Architecture and Specifications}
% ========================================================

The SmartClass platform uses a 24\,GHz FMCW mmWave radar (HLK-LD2410) coupled with an ESP32 microcontroller and a React web dashboard. The system operates on role-based access control (RBAC), dividing operational privileges between normal students/observers and Super Administrators.

Normal users have read-only access to live presence telemetry, 24\,GHz FMCW radar gate visualization, and the Web Serial USB gateway. Super Administrators possess full control, including admin role provisioning, gate threshold calibration, appliance manual overrides, and energy analytics.
